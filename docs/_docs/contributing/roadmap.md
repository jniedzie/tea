The main navigation contains workflows with enough documentation to use and verify them. The following areas have code or early helpers but do not yet have a complete supported guide.

## Incomplete documentation

- ABCD background-estimation helpers;
- a general end-to-end systematic-uncertainty prescription;
- Combine-based limits beyond the environment-specific tutorial exercise.

These are not presented as finished beginner features. Their current code can be inspected by advanced users, but an analysis must validate its own statistical and physics assumptions.

## Contribute a guide

A new guide should define prerequisites, a runnable example, expected output, failure modes, and a validation procedure. Open a [GitHub issue](https://github.com/jniedzie/tea/issues) to coordinate the scope before documenting an unstable interface.
