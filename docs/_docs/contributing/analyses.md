This page records analyses and training material that use `tea`. It is intentionally separate from the beginner tutorial so project-specific details do not obscure the supported workflow.

## Training material

- CMS DAS 2025 Hamburg long exercise: LLP analysis sequence covering histograms, plots, skimming, custom variables, data/simulation comparison, limits, and submission.

**Add an analysis**

Open a pull request with the analysis name, a stable public link, the input format, and a one-sentence description. Do not add private repositories or results that are not approved for public release.
